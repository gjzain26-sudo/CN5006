# CN5006 — Week 1 JavaScript Lab

This repository contains the Week 1 lab examples and portfolio exercise based on the supplied lab tutorial.

## Requirements
- [Visual Studio Code](https://code.visualstudio.com/)
- [Node.js](https://nodejs.org/) (includes npm)

Check your installation in the VS Code terminal:

```bash
node -v
npm -v
```

## Run the examples
Open this repository folder in VS Code, then run:

```bash
node week1/first-program.js
node week1/add-two-numbers.js
npm install
node week1/positive-negative-zero.js
node week1/arithmetic-operations.js
```

The interactive examples use `prompt-sync`, installed by running `npm install`.
